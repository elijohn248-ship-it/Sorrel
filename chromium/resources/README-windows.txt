Birch (Chromium) for Windows - test build from GitHub Actions
==============================================================

This is an early, unsigned test build of the Chromium edition of Birch.
It is not a release and does not update itself yet.

To run it:
1. Unzip the whole folder somewhere you can write to (for example your
   Desktop). Keep all the files together.
2. Double-click birch.exe.
3. Windows will say "Windows protected your PC". Click "More info", then
   "Run anyway". (Birch is not code-signed; that is expected.)

Your browsing data is kept in %LOCALAPPDATA%\Birch. Downloads go to your
Downloads folder. Ctrl+T new tab, Ctrl+W close tab, Ctrl+L address box,
Ctrl+Shift+N private window.

Licences for Birch and the parts it includes are in the "licenses" folder.
